# Tamagotchi

Um jogo de bichinho virtual 2D para web, feito com [Phaser 3](https://phaser.io/), [Vite](https://vitejs.dev/) e TypeScript.

## Como jogar

Cuide do seu bichinho alimentando, brincando, deixando-o dormir e curando-o quando ficar doente. Conforme o tempo passa, ele evolui por diferentes estágios de vida: **Ovo → Bebê → Criança → Adolescente → Adulto**. A qualidade dos cuidados que você oferece afeta o humor e a aparência dele.

O progresso é salvo automaticamente no `localStorage` do navegador, incluindo o tempo em que você ficou fora do jogo.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite (por padrão `http://localhost:5173`).

## Build de produção

```bash
npm run build
npm run preview
```
